## 📌 Repository Overview

Welcome to my personal archive of **picoCTF** walkthroughs! This repository documents solved challenges systematically by domain, difficulty tier, and problem set. Each writeup is organized to provide an intuitive, step-by-step breakdown from initial triage to flag extraction.

> [!NOTE]
> **Custom Flag Format:** All solved challenges across this repository follow the format:
> `academy{...}`
